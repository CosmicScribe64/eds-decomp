## Matching tricks learned

- Bitfield compares: a signed-looking test `x > 1` on an 11-bit bitfield is unsigned unless first copied into an `s32` local (`s32 a = s->rec[1].a; if (a <= 1) return 0;` matched; the `&&` chain and nested ifs did not, because agbcc rewrote the addresses as `r2 += 4`).
- The ROM often tests `count != 0` as `lsl #22; cmp #0` and extracts 2-bit fields as `lsl; lsr; cmp #0`. agbcc emits a mask instead for bitfield `!= 0`, but writes exactly the ROM form for manual shifts: `(*(u16*)p << 22) != 0` and `((b << 28) >> 30) != 0`.
- `switch` layout follows source order of the case bodies (jump table), and shared tails (`return 1`) are merged by agbcc; put case bodies in ROM order.
- A `switch` with two cases (`case 0`, `case 1`) puts the default first, then the case bodies: used in `0x08064420`.
- Do-while shape (`bls` at the bottom, no initial jump): `do { ...; row++; i++; } while (i <= 0x16);`. Indexing the table (`tbl[i].id`, `tbl[i].image`) makes agbcc strength-reduce two separate pointers exactly as the ROM does (`0x080648D4`).
- `struct Slide` fields are best accessed as direct globals (`gSceneWork.x`): the pointer-local form changed register use in `0x08064370`. Writing `to = target*80; base = to + 0x20; ...(to - from) * c / 4` keeps agbcc from distributing the multiplication.
- `u16 t = a * 0x62; t += 0x10;` produces the ROM's `mul; lsl #16; add #0x100000; lsr #16` sequence, whereas `u16 t = a * 0x62 + 0x10` does not.
- `0x03000000`-based accesses (`str r5,[r0,#4]`) need an extern struct symbol at that address (`IntrTable`) and a local pointer; a cast constant is folded.
- Return type `u16` for the predicates: callers then test with `lsl #16; cmp #0`, and a `u16`-returning switch adds `lsl; lsr` after calls.
- **Cast-constant table address stops loop-invariant hoisting** (`0x08063A28`): reading the packed card-key table through `((const u16 *)0x08623DF4)[i]` (an integer-cast constant) instead of `extern gCardNumberToId[i]` makes agbcc rematerialise the base inside the loop, exactly as the ROM reloads it. Do the lookup in a `static inline` helper (`IdToKey(u16)`, `int key`, cast address) and index the pack ids with `gPackOpenWork.ids[i]`; the ROM keeps `i` counting up (`ids[i]` is strength-reduced to a `+2` pointer).
- **Shared truth test after a `switch`** (`0x08064604`): writing cases `1..3` as `if (f()) goto advance; break;` lets agbcc merge the three u16 call results into one shared `lsl #16; cmp #0` at the switch tail. Assigning to a `u16 r` and testing `if (r)` instead adds a redundant `lsr #16`, and an early `return 0` in each case splits the test.
- **Explicit pointer and up-counter** (`0x08063D4C`): advance a pointer starting at `save.cards[1]` alongside the integer id in a `do`/`while` loop. A loop-bound local assigned at the loop tail and constrained to `r0` reproduces the ROM's rematerialized `0x334`; counter constraints to `r4` and `r3` retain its register roles. These constraints are marked `FAKEMATCH`. `if (have == total) return 1; return 0;` gives the target's final `beq` to the return-one branch.

## Pack-cover row matched (wave 1, 2026-10-01)

`PackList_DrawCovers` (0x118, start score 30) matches in ordinary C. Working notes: `build/wf/PackList_DrawCovers/NOTES.md`. It clears two gMain tile maps with DMA3 fills, zeroes `gMain+0x442A`, draws three pack covers for list rows `sel..sel+2` (mod the count at `0x0202037C`) at tile columns `0x62 + 10*i`, highlights the current slot (layer 4) and sets bit 0 of `gSceneWork.flags`.

- The parked draft pinned i, tile, s and list (r6/r9/r8/sl); the pins were unnecessary and made the loop tail wrong. The DMA prologue of the earlier draft (one function-scope `vu16 zero`, separate DmaSet/DmaWait scopes, `sel = arg` before `zero = 0`) was kept.
- Plain loop: `for (i = 0; i <= 2; i++)`, `gPackInfo[gSceneWork.list[sel]].id`, `(u16)(i * 10 + 0x62)`, `sel++; sel %= n;`. Loop strength reduction creates the 0x620000/0xA0000 induction variable in r9 by itself, and CSE derives the struct base from the list pointer (sl - 0x2C). Score 22.
- Hoist the count pointer: `u16 *cnt = &gUnk_0202037C;` before the loop, then `sel %= *cnt`. The pseudo gets no hard register; reload rematerializes it in the loop through its round-robin spill register (`ldr r2,=cnt`), and the 0xA0000 reload then moves to r5. Without the hoist, loop.c judged the move "not desirable" (life 1) and local-alloc put the address in r0. Score 12.
- Flag update through a u32 temporary: `u32 f = flags; f |= 1; flags = f;`. With `|=`, a u8 temporary or a u8 pointer, the address and the constant swap between r0 and r1. Score 0.
- Method: `old_agbcc -O2 -dl -dg -dL` dumps showed the remaining differences were reload round-robin choices (`allocate_reload_reg` / `last_spill_reg`), not local or global allocation. See [[matching-tricks#Register allocation priority and reload rotation]].

### `PackList_DrawBackground` (0x130, start score 83; ordinary C)

1. Which addresses are hoisted: the ROM loads the buffer base `0x0202037E` once (r2, before the first wait loop) and reloads each DMA source with a fresh `ldr`; the old draft had it the other way round. Fix: integer-constant sources (`dma[0] = 0x0863CE7C;`) and a symbol destination (`extern u8 gUnk_0202037E[]; dma[1] = (u32)&gUnk_0202037E[c << 6];`). SYMBOL_REF pseudos are CSE'd and hoisted across blocks, const_ints are not (symbol sources: 36; integer destination: 58).
2. Inner loop: a plain up-counting `for (j = 0; j <= 0x1F; j++)` with `(u16)j` in the index. loop.c reverses the counter (r2 = 31..0) and strength-reduces `(u16)j` into the `+= 0x10000` giv (r3), as in the ROM.
3. Outer loop: `for (i = 0; i <= 0x13; i = next) { u16 x = i; next = i + 1; ... (x << 5) ... a <= i && i < b }` gives the ROM's `lsl r0,r4,#16; add r6,r4,#1; str r6,[sp,#4]; lsr r1,r0,#11`, with `next` spilled.
4. Last step (104 -> 0): SDK-style separate DmaSet/DmaWait scopes, a fresh `vu32 *dma` per scope. With one scope the pointer is a global pseudo; b's hard-register preference for r1 (from its incoming argument copy) then kept every later global pseudo out of r1 in pass 0 of `find_reg`, so row/k and dma/mask/c+2 landed in swapped registers. With separate scopes the set-up pointers are block-local, local-alloc puts one in r1, b then conflicts with r1, its preference is pruned and global allocation picks the ROM's registers.
- Failed: symbol sources with a symbol destination (36), an integer destination (58), a single DMA scope (104).
