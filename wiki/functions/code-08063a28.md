## Matching tricks learned

- Bitfield compares: a signed-looking test `x > 1` on an 11-bit bitfield is unsigned unless first copied into an `s32` local (`s32 a = s->rec[1].a; if (a <= 1) return 0;` matched; the `&&` chain and nested ifs did not, because agbcc rewrote the addresses as `r2 += 4`).
- The ROM often tests `count != 0` as `lsl #22; cmp #0` and extracts 2-bit fields as `lsl; lsr; cmp #0`. agbcc emits a mask instead for bitfield `!= 0`, but writes exactly the ROM form for manual shifts: `(*(u16*)p << 22) != 0` and `((b << 28) >> 30) != 0`.
- `switch` layout follows source order of the case bodies (jump table), and shared tails (`return 1`) are merged by agbcc; put case bodies in ROM order.
- A `switch` with two cases (`case 0`, `case 1`) puts the default first, then the case bodies: used in `0x08064420`.
- Do-while shape (`bls` at the bottom, no initial jump): `do { ...; row++; i++; } while (i <= 0x16);`. Indexing the table (`tbl[i].id`, `tbl[i].image`) makes agbcc strength-reduce two separate pointers exactly as the ROM does (`0x080648D4`).
- `struct Slide` fields are best accessed as direct globals (`gUnk_02020310.x`): the pointer-local form changed register use in `0x08064370`. Writing `to = target*80; base = to + 0x20; ...(to - from) * c / 4` keeps agbcc from distributing the multiplication.
- `u16 t = a * 0x62; t += 0x10;` produces the ROM's `mul; lsl #16; add #0x100000; lsr #16` sequence, whereas `u16 t = a * 0x62 + 0x10` does not.
- `0x03000000`-based accesses (`str r5,[r0,#4]`) need an extern struct symbol at that address (`gUnk_03000000`) and a local pointer; a cast constant is folded.
- Return type `u16` for the predicates: callers then test with `lsl #16; cmp #0`, and a `u16`-returning switch adds `lsl; lsr` after calls.
- **Cast-constant table address stops loop-invariant hoisting** (`0x08063A28`): reading the packed card-key table through `((const u16 *)0x08623DF4)[i]` (an integer-cast constant) instead of `extern gUnk_08623DF4[i]` makes agbcc rematerialise the base inside the loop, exactly as the ROM reloads it. Do the lookup in a `static inline` helper (`IdToKey(u16)`, `int key`, cast address) and index the pack ids with `gUnk_02015160.ids[i]`; the ROM keeps `i` counting up (`ids[i]` is strength-reduced to a `+2` pointer).
- **Shared truth test after a `switch`** (`0x08064604`): writing cases `1..3` as `if (f()) goto advance; break;` lets agbcc merge the three u16 call results into one shared `lsl #16; cmp #0` at the switch tail. Assigning to a `u16 r` and testing `if (r)` instead adds a redundant `lsr #16`, and an early `return 0` in each case splits the test.
- **Explicit pointer and up-counter** (`0x08063D4C`): advance a pointer starting at `save.cards[1]` alongside the integer id in a `do`/`while` loop. A loop-bound local assigned at the loop tail and constrained to `r0` reproduces the ROM's rematerialized `0x334`; counter constraints to `r4` and `r3` retain its register roles. These constraints are marked `FAKEMATCH`. `if (have == total) return 1; return 0;` gives the target's final `beq` to the return-one branch.
