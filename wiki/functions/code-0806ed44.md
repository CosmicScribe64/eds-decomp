## Matching tricks
- **Direct `gMain.step` accesses, not `u8 *step = &gMain.step`**: the local pointer folds to one literal and puts the increment at `[r4,#27]`; direct accesses give the ROM's `ldr base; ldr #0x4859; add` (`sub_0806EF04/F01C/F05C`).
- **Jump table needs an explicit `case 0`**: `switch (mode) { case 0: return 1; case 1..4 }` makes gcc use the 5-entry table (`sub_0806ED64`); without `case 0` it builds a compare tree.
- **Bitfield stores**: `field = 0` on a 2-bit bitfield gives `mov #4; neg; and`; a raw `&= ~3` gives `mov #0xFC; and`. Use bitfields when the ROM shows `mov rX,#n; neg rX,rX; and`.
- **Reload after a store needs a pointer base**: `struct Main *m = &gMain; u8 *sub = &m->sub2; v = *sub; STEP2 = v; (*sub)++` re-reads `*sub` after the byte store (the ROM does); a global with a constant offset is treated as non-aliasing and reuses the register. Going through `m` also gives the unfolded `base + 0x485B` literal pair (`sub_0806F0BC`).
- **8-bit bitfield `|= 0xFF`**: `struct { u8 f : 8; }` keeps `ldrb; orr; strb` (a plain `u8 |= 0xFF` is folded to a constant store) (`sub_0806F404`).
- `(u8 *)&state + 0x1718` for a nearby object list makes gcc derive the state base as `obj - 0x1718` (`ldr =0xFFFFE8E8; add`), exactly as in the ROM.
- Separate pointer locals for adjacent bitfield bytes (`b7c`, `ba2`, `w84 = (u8 *)b7c + 8`) stop gcc from merging stores to the same byte across an intervening word store (`sub_0806F0F8`).
- `a = b = expr` for two byte stores keeps the shared-register tail (`b1BB7 = b1BB5 = 1 / 0`).
