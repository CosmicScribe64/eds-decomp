## Matching tricks

- `struct Main *m = &gUnk_03000040; m->field` (local pointer) makes agbcc build `base + 0x4868` in registers (`ldr r0,=base; ldr r2,=0x4868; add`) exactly like the ROM. Direct `gUnk_03000040.field` folds the offset into the pool word.
- Same for the save mirror: `struct Save *s; ...; s = &gUnk_02011C20;` assigned **after** the preceding call. `struct CardRec { u8 pad[8]; ... }` viewed at `(u8*)s + id*4` gives `ldrb [r5,#9]`.
- The sound helpers `sub_08077A44`/`5C` must be declared `u16` (callers test the result with `lsl #16`), and the `sub_0807E*` sound calls take `u32`-ish args (no narrowing at call).
- A bitfield of 11 bits inside a 4-byte struct is loaded with `ldr` (word) unless the struct is reached through a wrapper struct with leading padding (`struct Card2Rec { u8 pad[0x20D0]; struct Card2A a; }`); then it is `ldrh` like the ROM.
- `s32 a = w->a; if (a <= 0x7FE) w->a = a + 1;` gives `lsl #21; lsr #21; cmp; bgt` (compare on the extracted value).
- `count < 0x3FF` on a 10-bit bitfield compiles to the ROM's `lsl #22; cmp #0xFF800000; bhi`. `!= 0`/`> 0` on a bitfield compiles to a mask+cmp instead. Testing `(r->e.c.count << 22) != 0` preserves the target's test and matches `0x0807761C`.
- Copy loops: local copies `u8 *src = srcArg; u8 *dst = dstArg;` change the prologue order (narrowing of `u16` args first, then `adds r4,r0`), which the ROM shows. The `switch`-less `if (mode != 0x10) { if (mode == 0x100) ... } else { loop }` shape matches.
- `sub_08077C50`: `p = (u32*)(i * 4 + (u32)src)` (integer add, `i*4` first) reproduces `adds r3, r1, r7` operand order.
- OAM writers return the OAM pointer (`pop {r1}; bx r1`); `y` is `s16` (`lsl 16; asr 16; and 0xFF`), `x` is `((u32)x << 23) >> 23`.
- Switch with sparse cases (`0x080771A8`): agbcc emits the same compare tree as the ROM from a plain `switch`, and the case bodies must be written in ROM layout order. `gUnk_08623DF4[key + 0x1F]` in the case `0x3EB` makes CSE reuse the `0x40A` compare constant.

## Removal and trimming helper notes

- `0x0807766C` and `0x080776F8` match as C, verified in the whole 0x1368-byte unit. An empty initialized bits/flags input with r1 clobber stops the compiler from replacing `mov #13/49; neg` with a subtraction from the earlier constant 3. The search walks a byte offset while a separate signed index tracks the length. An explicit scan label and backward conditional jump retain the target's first scan body and literal-pool placement, and a nested guarded do/while compacts the tail. The u16 id ABI and all zero-count and absent-id behavior are preserved.
- Compiler register constraints on the record pointer, record offset, cached flags/shift, and count/list/compaction pointers were minimized with individual whole-unit checks. ## Complete OAM emitter and unit (2026-10-01)

Caching those halfwords in local variables changes common-subexpression lifetimes, register allocation and shared tails. This closes a 0x628-byte candidate down to the exact 0x5F0 target.

Corrected both coordinate parameters of the two local OAM helpers (`sub_08077E40` and `sub_08077E88`) to signed 16-bit values. The emitter sign-extends those arguments in the original assembly; both helper bodies remain byte-exact with these signatures. Reviewed callers that consume the result use count 1 and supported modes 4/8; other inspected calls discard the result. No extra allocation scaffold is present.
