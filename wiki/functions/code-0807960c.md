## Matching tricks (old_agbcc)

- **Bitfield flags**: `flags->newline = 0` compiles to the `mov r7,#2; neg r7,r7; and` pattern (int -2 mask) seen in the target; a plain `u8 &= ~1` gives `movs r0,#254`. The `OamList.count:7` field likewise reproduces `lsl 25 / lsr 25` and the `& 0x7F` increment.
- **Struct copy with pointer post-increment**: `*d++ = *s++; *(u16 *)d = *(u16 *)s;` matches the `ldmia/stmia` + `ldrh` copy in `OamListFlush`, while assigning struct fields makes gcc hoist a `+0x14` base.
- **Local copy of a bitfield to block CSE**: `u32 n, m = l->count; if (m > 0x7F) return 0; n = l->count;` reproduces the target's separate unsigned compare (a bitfield compared with 0x7F is otherwise folded to a signed test).
- **`<< 5` instead of `* 32`** in `dst[(x + j & 0x1F) + ((y + i & 0x1F) << 5)]` fixes operand order of the final add (`FillTilemapRectWrap`).
- **Shadow text**: `(t1 = (t = n * (c >> 1)) + 1) + x` in the first call and `t + x` in the second stops gcc from reassociating `(1 + x)` and reproduces the exact registers of `DrawStringShadow` / `...JIS`.
- **Fields typed `u16` for compares**: `Line.acc` is `u16` and `dx/dy` `s16`; the compare `acc >= dy` then produces `ldrh` versus `ldsh` exactly as in the target.
- **Pass-through wrappers** (`DrawStringShadowAuto`) need the callee prototypes with the same narrow types, so caller-side narrowing matches.
- **A digit/character range check must be a `switch` with dense cases** (`case '0': ... case '9':`), which old_agbcc emits as the two-compare range test `cmp #hi; bgt; cmp #lo; blt` on the int value. A `||` of two compares folds into an unsigned `(c - lo) > hi-lo` test (`sub #lo; cmp #9; bhi`), and separate `if`s canonicalise the second bound to `cmp #lo-1; ble`. Same rule as `case 2: case 3:` in [[code-0806704c]].
- **Permuter register tricks** (`/* FAKEMATCH */`): a dead assignment keeps a computed value in the register the ROM used (`r = (t = v - '0') + s[1]` in `ParseDecimal2`); a dead `int addr = <first dst offset>` plus a `row2 = row` copy pins the address/value split in `PlotGlyphRow16`. Same idea as the `ret = zone = 1;` pattern in [[decomp-permuter]].
- **`*(volatile u8 *)s`** on a repeated byte read forces the ROM's extra `ldrb` when agbcc would otherwise CSE it (`TextFits`).
- **OAM list clear** (`0x0807A2EC`): initialise the byte loop counter before the `0xFF` fill value, then use an empty input barrier on each loaded head byte before the OR. Clearing the `count:7` bitfield supplies the target's negated mask instead of a folded `& 0x80`.
- **Signed field reloads** (`0x0807A398`): empty memory barriers after the direction stores and before subsequent comparisons force the target's field reloads. Passing each `s16` delta through an `int` temporary and an empty input barrier retains `ldrsh` for the negation. These barriers emit no instructions.

## Nonmatching notes

- `0x0807960C`: target hoists `(y & 0x1F)` and spills `x`; built hoists `y - 1` and keeps `x` in r7 (structure and flag ops match). Trick sweep (2026-09-30): goto loop (trick 3) over-spills `dst`/`a`/`b`; a named `yy = y & 0x1F` local double-hoists (also using `(yy-1)`); a `>1` if/else or a local `nx` does spill `x` but flips flags to r7 and picks the wrong scratch registers. No match.
- `0x08079700`, `0x080798B8`, `0x08079B88`: register allocation only (details in each `#if 0` comment). Permuter runs on `0x08079B88` (best 989) and `0x080798B8` did not converge.
- `0x08079FDC`: target keeps the loop bound 8 in `sl` and hoists `color<<8` but recomputes `color<<16`; built hoists `color<<16` into r6 and puts `i` in ip. Trick sweep: goto loops (trick 3) drop *all* high-register hoisting (no `r8`/`r9`/`sl`/`ip`); a loop-bound local folds to 8; a 64-bit temp on `color<<16` (trick 2) spills `color`. No match.
- `0x08079ED4`: converted via permuter (score 0). The target reloads `s[1]` inside the branch and computes `(v-0x30)+s[1]` subtract-first; dead assignments `r = (t = v - '0') + s[1]` force that order (`/* FAKEMATCH */`). Without them agbcc CSEs the load and reassociates.
- `0x080799BC`: converted via permuter (score 0). A dead `int addr` holding the first `dst` offset plus a `row2 = row` copy force the target's register split (half kept in r5, row in r4, loop counter r3) (`/* FAKEMATCH */`).
- `0x08079A48`: converted via permuter (score 0). A temporary `u32 hi = g >> 8` for the byte-swap (instead of inlining `g >> 8`) pins the target's registers (`/* FAKEMATCH */`).
- `0x08079F40`: converted by hand. `*(volatile u8 *)s` on the two `== '$'` tests stops agbcc CSEing them with the loop-condition load (`/* FAKEMATCH */`); the tail must be written `if (a + w > limit) return 0; return 1;` to get the target's branch polarity.
- `0x0807A1A8` (now matched; see the last section): the target keeps the ring base in r9 and the fill value in r8; built reloads the pool constant and puts `size` in r9. Permuter best 1630 (no match). Trick sweep: local, extern-symbol, `u32` and inline-literal forms of the base all get rematerialised from the pool (tricks 1/2/4/6); inlining the literal also spills `mask`. No match.
- `0x0807A5D4`: target keeps `((w<<24)>>25)` plus a redundant `u8` narrowing of `half`, spilled to `[sp]` and reloaded per row (stride in `[sp+4]`); built folds `half` into r7 and the stride into `sl`. Trick sweep: writing the exact double-narrowing expression and adding explicit `stride`/`next` locals (tricks 1/6) do not raise register pressure enough to force the spill. This was the same blocker as `0x0807A754`; both matched in wave 1 by dropping the `half` local (see below).

## `sub_0807A1A8` (LZSS) matched (2026-10-01)

Three changes, all ordinary C ([[lzss-decompress]]):
1. The ring index `r`, match position `p` and byte `b` are `u16` locals (lossless: `r`/`p` are masked to 12 bits, and `b` holds a byte or the masked high nibble). The climber found these.
2. The declaration order is `r`, `i`, `p`, `b` (also from the climber).
3. The match length lives in the inner loop condition, `for (i = 0; i < b + 3; i++)`, with no `len` local. Loop-invariant hoisting then places `b + 3` after `i = 0`, as in the ROM (`movs r2,#0; adds r1,#3; mov ip,r1`).

Related: [[code-0807a6ac]], [[lzss-decompress]], [[decomp-workflow]], [[compiler-flags]].

## Ascending tile fill matched (wave 1, 2026-10-01)

`sub_0807A5D4` (0xD8, start score 38) and its sibling `sub_0807A754` in [[code-0807a6ac]] match in ordinary C with the same shape, each on the first try. Working notes: `build/wf/sub_0807A5D4/NOTES.md`.

- The target computes `(w<<24)>>25`, narrows it to u8 again, keeps `half<<24` spilled in `[sp]` and recomputes the inner bound per row. Earlier drafts used a `half` local, which agbcc kept in a register.
- What matched: **no `half` local**. Write `w / 2` inline in both the inner loop bound (`j < w / 2`) and the stride (`p += 0x10 - w / 2`), with `u8 i, j`. c-typeck shortens `u8 / 2` to an unsigned-char division, which is the redundant u8 narrowing. The rotated loop's two condition copies are hoisted differently, which produces the `[sp]` spill and the per-row reload.
- Failed earlier: `u8`/`s16` `half` locals, the explicit double-narrowing expression, explicit stride/next locals.
- This overturns the "explicit spills are difficult" entry for these two functions in [[matching-tricks]]: the spill came from the compiler's own loop-condition copies, not from register pressure.
