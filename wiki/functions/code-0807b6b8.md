# code_0807B6B8: sprite setup, tween update, Konami link (SIO) accessors and a link/password menu (`0x0807B6B8`-`0x0807C7C8`)

`src/code_0807B6B8.c` (28 functions, 0x1110 bytes). **23 / 28 are C and byte-matching**; 5 stay `INCLUDE_ASM` (`sub_0807C4CC` not attempted; the other four have drafts under `#if 0 /* NONMATCHING */`). The unit links to the exact target bytes. Compiler `old_agbcc -O2`. Names are proposals; the code keeps `sub_08XXXXXX`. Follows [[code-0807a6ac]]; uses the OAM list of [[code-0807960c]] (`sub_0807A320` = list alloc).

The last third (`0x0807BCFC`-`0x0807C4CC`) is the **two-player link ("BASICSIO") handshake and the link/password menu screen** that shares state at `0x0201F7B0` (0x18 bytes).

## Structures (as declared in the unit)

- `Tween {u16 x, y; u16 x0, y0; u16 x1, y1; s16 step, step2; s16 dx, dy; u8 kind @+0x14; u8 mode @+0x15}`. `kind` 1 = running, 2 = finished.
- `LinkSync {LinkEntry tx @+0, rx @+4; u8 state @+8; u16 timeout @+0xA}`, `LinkEntry {u8 id, phase; u16 data}`. States: 0 reset, 1 send, 2 wait for reply (rx phase 1 means the same id, so answer with phase 4; rx phase 3 restarts; rx phase 4 means the peer acknowledged), 3 goes to 1, 5 finish.
- `LinkState @0x0201F7B0 {u8 pad[0x10]; u8 cur; u8 a:6; u32 b:6; u16 c:12; u16 d}` (bitfield layout inferred from the clear masks; byte 0x10 low nibble = selected digit slot, high nibble = cursor entry).
- SIO registers: `0x04000120-0x04000128` (SIOMULTI0-3, SIOCNT), `0x0400012A` (SIOMLT_SEND), `0x04000134` (RCNT). `SIOCNT` bit 7 start, bit 6 error, bit 3 SD, bit 2 SI, bits 4-5 player id.

## Matching tricks learned (old_agbcc)

- **Struct with a big offset instead of `sym + N`**: `extern struct {u8 pad[0x485E]; u16 x;} gUnk_03000040;` makes gcc emit `ldr r0,=0x03000040; ldr r1,=0x485E; add` exactly like the target, while an array index folds into one pool entry `sym+0x485E`. A second view of the same symbol uses `extern struct X gUnk_03000040_b asm("gUnk_03000040");`.
- **Prototype return type of a helper** decides operand order in the caller: `sub_0807BED8` declared `u16`-returning (via `asm` alias) gives `eors r1,r0` (result register = the constant) in `LinkHandshakeStep`; `u32` gives `eors r0,r1`.
- **Fall-through without `break`** (`TweenUpdate` case 2 into case 3) is in the original code; add it explicitly.
- **Tail duplication**: `TweenInit` cases 1 and 2/3 contain identical code; gcc's cross-jumping merges them only from the `asr` on (the target has the duplicated first `lsl`).
- **Bitfield stores** (`u8 a:6`, `u32 b:6`, `u16 c:12`) in the link state reproduce the `ldrb/ldr/ldrh + and mask` sequences of `LinkStateInit` (and `count:7` of the OAM list in [[code-0807960c]]).
- **Local pointer copies** in `LinkHandshakeStep` (`tx = &p->tx; rx = &p->rx; st = &p->state`) reproduce the hoisted `p`, `p+4`, `p+8` registers (r4/r6/r7).
- **`u16` field with `--x == 0xFFFF`** gives the `lsl 16; cmp 0xFFFF0000` timeout test; `s16 == -1` gives `asr`.
- **DMA loop**: `vu32 *dma = (vu32 *)0x040000D4; dma[0..2] = ...; dma[2]; while (dma[2] & 0x80000000);` matches the sequence with two reads.

## Nonmatching notes

- `0x0807B6B8`: case constants/layout match; the u16 narrowing of `x`/`y` lands in the prologue (built) vs at the use (target), and r4/r6 are swapped.
- `0x0807B864`: register allocation only (target: count in sl, the last u8 arg in r8; built: swapped).
- `0x0807B9D4`: see tail-duplication above; also in-place sign extension vs two-register extension.
- `0x0807C1D0` (solved): the `0x776..0x778` range must be a `switch (n) { case 0x776: v = 3; case 0x777: case 0x778: v = 1; default: ... }` (copy the sibling's `CardFrameKind`). That emits the ROM's two signed compares instead of a folded unsigned range test. The last hurdle was argument-setup order in `sub_08072EB0(0x420, 0x20, 0x100, tbl)`: pin the two scalar args as `register u32 a asm("r0") = 0x420; register u32 b asm("r1") = 0x20;` so agbcc sets r0, r1, then the shifted `0x100` (otherwise it schedules `0x100` before `0x20`).
- `0x0807C304` is matching: initialize the pack-loop counter before its pointers, cache the packed first byte before scanning, and express the table as the fixed ROM pointer `(u8 *)0x08623120 + n * 4` to retain its in-loop literal load. A local buffer-pointer constraint to `r4` is marked `FAKEMATCH`; no inline assembly instructions are emitted. Verified with `tools/check.py`: 28/28 functions match and unit bytes MATCH (0x1110 bytes).
- `0x0807C46C` is matching: an empty input barrier for `mask = 15` and `zero = 0` immediately after clearing the state schedules the shared constants before the bitfield stores. No instructions are emitted by the barrier. Verified with `tools/check.py`: 28/28 functions match and unit bytes MATCH.
- `0x0807C058` now has a full C draft for clearing/filling the portrait map and unpacking the 6bpp image. Counter allocation (`ip` versus `r8`) and table/mask hoisting remain nonmatching.
